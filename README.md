# Character Icon Workspace

雪・夏・楓・桜花の新規アイコン画像を管理するリポジトリ。

## 運用方針

- 旧GitHub Pages顔アイコン配信実験は終了。旧 `avatars/` 画像と `index.html` は撤去済み。
- PC上・ブラウザ拡張内の現役アイコンはここへ再登録せず、変更もしない。
- 新しい画像は候補として追加し、ユーザーが承認したものだけ正式採用とする。
- 新規画像の作成順と採用状況を記録する。最新版と正式採用版は区別する。
- このリポジトリは **public**。アップロードした画像は誰でも閲覧できる。

## 今後の配置案

- `candidates/` — 未採用・確認待ちの新規画像
- `approved/` — ユーザーが採用を明示した画像
- `archive/` — 旧版・不採用画像

現時点ではフォルダ構成は提案段階。画像はまだ登録していない。

## 注意

Git履歴には以前の画像が残る。公開履歴からの完全消去は別作業。
