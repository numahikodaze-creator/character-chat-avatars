# Character Icon Workspace

雪・夏・楓・桜花の表情アイコンをキャラクター別に管理する公開リポジトリ。

## ディレクトリ構成

- `YUKI/` — 時代 雪
- `NATSU/` — 時代 夏
- `KAEDE/` — 雨月 楓
- `OUKA/` — 葉山 桜花

各フォルダには `<CHARACTER>.png`（基準 NEUTRAL 画像）と、`<CHARACTER>_<EXPRESSION>.png`（表情アイコン）を置く。

例:
- `YUKI/YUKI.png`
- `YUKI/YUKI_LAUGH.png`
- `NATSU/NATSU_PANIC.png`

## 運用

- 画像は ZIP のままではなく、**個別 PNG** としてコミットする。
- 同じ表情タグは4人共通で使えるように、順次不足分を制作する。
- 画像は原則 512×512 PNG。ファイル名は大文字のキャラ名と表情タグを使う。
- 基準画像や既存画像の上書きは慎重に行う。
- このリポジトリは **public**。アップロードした画像は誰でも閲覧できる。
- 古い画像は Git 履歴に残る。公開履歴からの完全消去は別作業。
